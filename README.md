# Ulang Tahun Liya ♡

Situs ucapan satu halaman untuk merayakan 7 Oktober. Dibuat dengan HTML, CSS, dan JavaScript murni agar ringan, responsif, dan mudah diterbitkan lewat GitHub Pages.

## Isi situs
- Kartu scrapbook dengan ilustrasi kue buatan CSS.
- Empat kartu harapan untuk tahun baru Liya.
- Amplop interaktif berisi surat ucapan.
- Tombol meniup lilin, konfeti, dan membagikan tautan.
- Layout ponsel, fokus keyboard, label aksesibel, dan dukungan gerakan terbatas.

## Menjalankan dan mengubah isi
Buka **index.html** di browser. Tidak ada paket atau proses build. Ubah teks di **index.html**, tampilan di **styles.css**, dan interaksi di **script.js**.

## Publikasi
Workflow di **.github/workflows/pages.yml** menerbitkan situs ke GitHub Pages pada setiap push ke branch **main**. Jika perlu, pilih **Settings → Pages → Build and deployment → GitHub Actions** di pengaturan repository.
